= Bluesky Boot

Bluesky Boot 는 Spring Boot 를 확장한 라이브러리입니다.
애플리케이션 하나가 도메인 · 경로별로 여러 모듈(사이트)을 서비스할 때, 모듈마다 다른 설정을 쓰도록 돕습니다.

== 기능

* 모듈 지원: 요청의 도메인 · 경로로 모듈을 고르고, properties 를 parent · group · module 순서로 합쳐 모듈별 설정을 제공
* 모듈별 locale · cookie · 도메인 설정과 locale resolve handler
* 여러 message basename 을 합친 MessageSource
* 여러 DataSource 와 routing DataSource
* 공통 예외 응답(ProblemDetail), UUID 생성기, htmx 지원, TextEncryptor

== 구성

* Java 25, Spring Boot 4, Maven
* `bluesky-boot-build/`: maven 모듈 (`bluesky-boot`, `bluesky-boot-autoconfigure`, `bluesky-boot-test-autoconfigure`, `bluesky-boot-properties-migrator`, `bluesky-boot-docs`, `bluesky-boot-dependencies`, `bluesky-boot-parent`)
